# 白板手绘 Whiteboard — 风格规格

> 白板上边讲边画：字一笔一笔写出来、框画得略歪、讲完用板擦擦掉；红色马克笔把重点圈起来。
> 借鉴（只学语法）：白板讲解视频和手绘解说动画（边画边讲、圈重点、打勾、箭头）；会议室里的真实白板。不照搬任何解说动画品牌的角色、手和画风。

## 1. 本质，以及它不是什么

- 一眼认出：**白底 + 手写体标题**、**边线微微抖动的框**、**字逐个写出且略有倾斜**、**红色马克笔圈注**。
- 气质是"我给你讲清楚"：亲切、慢、一次只讲一件事。
- 不是蓝图（线不精确、不是蓝底）；不是杂志（不是衬线排版、不是纸张质感）；不是波普（没有半调、没有硬阴影、不弹跳）。

## 2. 材质与渲染

- 白板：`--bg` 近白，略带冷灰；不画网格（可加极淡的擦痕）。
- 框：`.card` 白底 + `::after` 伪元素画一圈 3 px 马克笔边（不规则圆角），经 `#wb-rough`（`feTurbulence` 固定种子 7 + `feDisplacementMap`）让边线微抖。**滤镜是静态的，从不动画**，否则线会"游动"。
- 每个框有一个由文字内容和位置决定的固定小倾角（±0.6°），同一个框每帧一样。
- 没有阴影、渐变、发光。

## 3. 色彩逻辑

- 马克笔四色：黑（`--ink`，正文和线框）、蓝（`--c1`，结构、流程）、绿（`--good`，好、完成）、红（`--accent` / `--bad`，重点和问题）。
- 红色只用于圈、勾、划掉和一个关键词；一屏最多一处。
- 渐变词（`.g.warm` / `.g.cool`）在本风格是单色马克笔色，不是渐变。

## 4. 字体与字幕

- 标题：手写体（Segoe Print / Ink Free / 楷体 KaiTi / 华文楷体）；正文：系统无衬线（雅黑 / 苹方），保证可读。
- 不要整段都用手写体：只给标题、标注、关键词。
- 字幕：白底、2.5 px 黑框、四角圆角各不相同，像手画的对话框。
- 手写字间距稍大，行距 1.3 以上。

## 5. 运动质感

- 写字速度：`K.text` 每字 55 ms 以上，单字 0.09 s 内"落笔"（从 1.18 倍缩到 1 倍并出现），每个字有固定小倾角（±2°，由文字和序号决定）。
- 框：`K.item` 从左向右画出（`inout`），带固定倾角；离场被板擦从左往右擦掉。
- 场景：入场淡入，离场板擦横扫。
- 没有回弹、没有模糊；节奏比别的风格慢 20–30%。

## 6. 镜头语法

| 动作 | 表达 | 适合 |
|---|---|---|
| 固定机位，边画边讲 | 一步一步推理 | 原理、流程、方法 |
| 画完拉远看全图 | 原来这些是一个整体 | 章节小结、架构总览 |
| 推近一个框 | 现在讲这一块 | 展开某一步 |
| 板擦擦掉重画 | 换一种思路 | 旧做法 → 新做法 |
| 圈出 + 箭头指向 | 就是这里 | 痛点、关键差异、结论 |

## 7. 声音调色板

- `music.mjs` palette **felt**：温暖 pad、毛毡钢琴琶音、刷子 hats、没有底鼓；tick = 钢琴单音，whoosh = 纸张/板擦摩擦，impact = 一个钢琴和弦 + 轻低频。
- 拟音：马克笔在白板上"吱"一声（每个框一声）、笔帽合上、板擦擦过。
- 讲解片音乐要低：旁白下 −20 dB 以下，句间不抢。

## 8. 招牌动作

- **马克笔圈重点**（`hit` 已实现）：红色椭圆一笔画过一圈多，左侧补三道强调线。*适合*：logo 落定；"这就是区别"；最关键的一个数。
- **逐框画出流程**：框 → 箭头 → 下一个框，每画一个讲一句。*适合*：工作流；用户旅程；三步上手。
- **打勾清单**：每讲完一条打一个绿勾。*适合*：功能列表；准备事项；验收标准。
- **划掉重写**：旧词被红线划掉，旁边写上新词。*适合*：旧流程 → 新流程；误区 → 正解。

## 9. 常见坑

- 滤镜按帧变化 → 线条抖动像信号不好。种子固定，不要动画。
- 倾角按调用顺序分配 → 同一个框不同帧角度不同。用文字 + 位置的哈希（已如此实现）。
- 手写体没有中文字形 → 中文回落楷体；楷体太细时标题加粗到 700。
- 框里字太多 → 白板一框一句，长句拆两框。
- `.card` 绝对定位时 `::after` 依赖 `position`；theme 用 `:where(.card:not(.abs))` 给非绝对定位的框补 `position: relative`。

## 10. 引擎

- `style.js`：注入 `#wb-rough` SVG 滤镜；`text`（落笔写字 + 固定倾角，离场左到右擦掉）、`item`（左到右画出 + 固定倾角，板擦离场）、`mask`、`lockup`（标记左到右画出，名字慢写）、`scene`（淡入，板擦离场）、`hit`（红色椭圆 + 三道强调线，2.6 s 后淡出）。`draw` 为 `inout`，连线不带火花。
- 可调：`tilt()` 的幅度、`hit` 里椭圆半径 `rx`/`ry`（默认按 1920 宽的 lockup 尺寸）。

## 11. 变化空间

- 结构：**一张白板讲完**（全片不换场，越画越满，最后拉远看全图）；**问题 → 擦掉 → 答案**（左半边画问题，擦掉，右半边画答案）；**三格连环画**（三个框三幕，最后一格是产品）。
- 开场：**一个红圈先出现**，里面还是空的；**一个大问号**写在中间；**一句话写到一半停住**，等旁白接上。
- 结尾：**整板擦净，只剩 logo 被圈起来**；**拉远看到满满一板，最后写下日期和名字**；**笔帽合上的声音，然后黑场**。
