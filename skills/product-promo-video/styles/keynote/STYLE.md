# 暗场发布会 Dark Keynote — 风格规格

> 软件发布片，主角是界面本身：近黑舞台、发丝网格、柔和冷光、**唯一一个**发光强调色；元素卡准网格和节拍落位，光带扫过才被点亮。
> 借鉴（只学语法）：大型科技发布会的产品揭幕（黑场、光扫、一屏一句、单独一个巨大数字）；SaaS 发布短片（卡拍运动、1 px 线、一个强调色）；过程音乐（相位、增减）。不照搬任何界面、系统控件、字体文件、旋律和 logo。

## 1. 本质，以及它不是什么

- 一眼认出：**近黑 + 发丝网格**、**一个荧光强调色**只给最重要的元素、**大量留白**、**一个巨大的数字独占一屏**。
- 气质是**精确**：一切落在网格和拍子上，戏剧性来自"杂乱 → 一个果断动作 → 空"。
- 不是星云玻璃（没有渐变、没有粒子、没有彩色光晕）；不是终端（不是等宽满屏）；不是玻璃产品渲染（没有实物）。

## 2. 材质与渲染

- 舞台：`--bg` 近黑，上方中央一团 7% 白色抬亮，右下极淡强调色光晕，四角 55% 暗角；48 px 细网格（白 2.8%）+ 每 4 格一条粗线（白 5.5%）。不加颗粒。
- 表面：三级深灰面板（`--card` 等），1 px 边（白 8.5%）+ 1 px 顶部内高光 + 软阴影。圆角 16 px。
- 光是揭示工具：`hit` 时一条柔光带横扫；只有被扫过的地方是亮的。
- logo 标记：深色方块 + 细边，折线和点用强调色（`.mk-*` 在 theme.css 里改）。

## 3. 色彩逻辑

- 冷中性灰阶：近黑、三级面板、三级文字灰（`--ink` / `--sub` / `--dim`），微偏蓝，绝不偏暖。
- **一个强调色**（默认青柠 `#b7f34a`）只给产品是什么/做什么：主角元素、行动号召、完成态、关键数字。两样东西都用强调色，其中一个就是错的。
- **问题色**（`--bad` 红）只在问题存在时出现，转折之后不再回来。
- 类别色 `--c1..--c6` 全部是去饱和的灰蓝/灰绿，只在运动中区分类别。
- 可换的强调色示例（一片只选一个）：青柠 `#b7f34a`、电紫 `#8b7cff`、信号橙 `#ff7a1a`；改 `--accent` 和 style.js 里的 `ACCENT`。

## 4. 字体与字幕

- Inter / Segoe UI Variable + 微软雅黑；标题 600，字距 −3%；标签、文件名、状态用等宽字（`--mono`），小号加宽字距。
- 一屏一句标题。大数字独占一屏，**上面不压字幕**。
- 字幕是界面组件：底部居中的深色胶囊 toast，1 px 亮边，左侧一个强调色"说话中"小点。
- 屏幕上正在被打出的字就是字幕，不再重复烧录一遍（只进 .srt）。

## 5. 运动质感

- 30 fps，无步进、无抖动：这是精确，不是手作。
- **一切落在拍子上**：动作提前一拍开始、在拍点落位。缓动 = 快出 + 一个小回弹（`K.back(x, 1.3)`）+ 立即停稳。没有飘忽的正弦漂移。
- `K.text`：字符被光点亮（亮度短暂升高）+ 10 px 回弹上浮，间隔 24 ms；离场从尾到头逐字熄灭。
- `K.item`：落下 + 小回弹 0.45 s；离场像 CRT 关机——纵向压成一条线再消失，**不淡出**。
- 舞台和网格自己永远不动，只有镜头动它们。

## 6. 镜头语法

| 动作 | 表达 | 适合 |
|---|---|---|
| 锁定特写一个小 UI 元素 | 屏幕上只有一个东西是活的 | 一个动作、一个状态点 |
| 连续拉远（按小节在对数空间） | 从一个点长出规模 | 负载扩散、网络增长、团队加入 |
| 冻结帧中推近 | 时间停住、焦点收窄 | 提交前一刻、发现缺陷 |
| 一拍内甩出全景 | 因果同屏 | 同步完成、部署到所有地方 |
| 半秒插入镜头从源头展开 | 信息过载 | 通知风暴、报错、选择困难 |
| 近乎锁定 + 光扫 | 呈现、英雄时刻 | 揭幕、新版本、功能名 |

转场 = 面板展开/收拢（`scene` 钩子：从中线上下展开、收拢到中线），没有淡入淡出、没有空帧。

## 7. 声音调色板

- `music.mjs` palette **mallet**：正弦 pad、sub bass、毛毡底鼓、shaker、马林巴琶音（FM 金属泛音）、玻璃 tick、和弦式 impact（马林巴和弦 + 低频）。
- 音乐即可见的过程：可以一小节加一个音、可以减到只剩一个音；画面事件落在乐谱音符上。
- 两个声音家族讲故事：杂乱 = 分散（随机声像、不同音色）；产品 = 一个家族（同一调式、居中），很多元素落位合成一个和弦。
- 静音是工具：屏幕停住时所有轨道归零；静音之后的第一个声音是最重要的那个。

## 8. 招牌动作

- **生成式堆积**：按规则生成上百个 UI 元素，越来越快；不手画混乱，而是生成它。*适合*：未读工单堆积；云成本爬升；依赖树爆炸。
- **一拍归位**：所有元素在一拍内飞进网格。*适合*：一键发布到所有渠道；排期填满一周；审计全部变绿。
- **光扫揭幕**：柔光带横扫，只有被扫过的像素亮起（`hit` 已实现）。*适合*：改版、新定价页、新控制台。
- **字形噪声锁数**：数字先乱码，每个十六分音符锁定一位。*适合*：延迟降低、用户数、价格。
- **冻结**：所有东西停在半空，声音降到数字零。*适合*：拦截了一次泄露；部署失败；"发送"前一秒。

## 9. 常见坑

- 白色硬高光像贴纸 → 光带前沿要软，峰值 ≤ 20%。
- 强调色用在两处 → 去掉一处，或把另一处改成 `--ink`。
- 网格里空洞太多像错误 → 元素按规则生成，再补齐到槽位数。
- 场景内也在用 transform 推近时，`scene` 钩子只能用 clip-path 和 opacity（已如此实现）。

## 10. 引擎

- `style.js`：`text`（光点亮 + 回弹）、`item`（落下回弹 / 纵向压线离场）、`mask`、`lockup`（标记 0.9 → 1 回弹，名字逐字点亮）、`scene`（中线展开/收拢）、`hit`（预备时一圈收缩的细环和亮点 → 光带横扫 + 强调色细环扩散 + 中心微光）。
- 可调：`ACCENT`（RGB 字符串，和 `--accent` 一致）、回弹强度 `back(p, 1.3)`、光带宽度 260 px。

## 11. 变化空间

- 结构：**发布清单倒数**（每勾掉一项是一个界面时刻，最后是"已上线"）；**分屏对照**（旧流程淹没、新流程提前完成）；**缩放阶梯**（一个像素 → 一个组件 → 一屏 → 一整个设备群）。
- 开场：**数字先出**（黑场里一个巨大数字，意义倒着揭示）；**空网格俯视**，一格一格被填满；**第一帧就是插入镜头风暴**。
- 结尾：**空网格里只剩一格亮着强调色**；**产品在全景里安静运行，没有字**；**一个"已完成"toast，然后黑场**。
