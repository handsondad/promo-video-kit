# 宣传片手艺：SPEC、故事线、结构、文案、节奏、声音、诚信

评判一部片子的顺序：**声音、节奏、镜头、导演**（一个主角、一个目标、一个转折）。好看的单帧只是起点。

## 开工前：把需求问成能照做的样子

工作流第 2 步那一条消息里，除了片型、风格、画幅、时长，再确认五件事：

- **合作方式**：用户要一次出完整片，还是每段（SPEC → 故事线 → 风格帧 → 粗剪）都确认一次。
- **逐字锁定**：用户给的口号、产品名、数字、免责声明原样用，不改写、不"润色"；写进 SPEC 的 LOCKED 一栏。
- **主张和行动号召**：各引用用户的原话；没有就写一句给用户确认，不自己编。
- **素材路径**：录屏、截图、logo、字体、授权曲各在哪；缺的明说，用占位还是先补。
- **角度**：同一个产品可以讲给决策者、使用者或开发者，先定讲给谁。

## 先写 SPEC：把形容词变成数字

"高级""有冲击力""简洁"不能执行。动手前在片子目录写 `SPEC.md`，每一项都写成能检查的数：

| 项 | 写什么 | 例 |
|---|---|---|
| GOAL | 看完的人要记住哪一句、去做哪一件事 | 记住"一句话就能跑完一次推演"；去申请试用 |
| OUTPUT | 时长、画幅、帧率、平台 | 40 s，1920×1080 30 fps，官网首屏 + 会议开场 |
| TIME | 每段几秒（按下面的节拍比例） | 钩子 3 s，转折 5 s，揭示 3 s，证据 16 s，回报 8 s，口号 3 s，片尾 3 s |
| LOOK | 风格、底色、主色、字体、字号下限 | swiss，纸白底，单一红色强调，标题 96 px，最小 28 px |
| OBJECTS | 画面里出现的东西，每个是什么材质 | 真实界面录屏、一张卡片、一条曲线；不出现 3D、人物 |
| MOTION | 入场、离场、镜头、转场各用什么，各多快 | 入场 0.5 s expo.out，离场 0.3 s，转场 3 种 |
| SHOTS | 镜头表：景别、运动、时长、为什么 | 见下面的 Treatment |
| BANNED | 这部片子不用的东西（从下面的黑名单里挑，再加题目自己的） | 不用玻璃卡片、不用粒子、不从打字框开场 |
| LOCKED | 逐字不动的文字和数字 | 口号"一句话就够"；片尾免责声明全文 |
| QA | 交付前要过的检查 | check.mjs 无 P0，审片图过一遍，响度 −16…−14 LUFS |

SPEC 写完给用户看一眼（一句话问"按这个做？"），然后照着做；中途改主意先改 SPEC。

## 默认值黑名单：一眼就像"生成的"

下面这些是没有设计时会自动冒出来的默认值。每一条都可以用，但必须是**为这个题目选的**，不能是因为顺手：

- 深海军蓝的虚空背景，上面飘着小元素；辉光、光晕、霓虹、粒子。
- 紫蓝渐变、网格渐变、毛玻璃卡片。
- 米色纸 + 衬线大标题 + 等宽小标签 + 胶囊标签。
- 所有东西居中、淡入、上滑；标题落定后还在慢慢漂。
- 角落里的小标签和 HUD 装饰；三张卡片并排、KPI 网格。
- 标题压在暗化的截图上；logo 一直停在角落。
- 用"在输入框里打字"开场。
- 顺手就用的字体：Inter、Space Grotesk、Instrument Serif、Geist、JetBrains Mono（`swiss`、`keynote` 的字体栈把 Inter 排在前面，
  是因为网格和发布会风格要一款中性的新怪诞无衬线，这是选过的；品牌有自己的字体就在品牌层换掉）。

本 skill 的默认风格 `nebula`（深色、玻璃卡片、粒子）和动效模板（打字、三卡并排）恰好集中了好几条：
它们是起步脚手架，不是答案。用户没指定风格时，按内容从 [styles.md](styles.md) 里挑，**不要因为 nebula 是默认值就用它**；
做完对照这张表，列出这部片子用了哪几条、为什么。

## 三条故事线（写在 `STORYLINES.md`，选一条再写 Treatment）

同一个产品写三条完全不同的故事线，每条定三件事：

- **世界**：画面发生在什么地方（一个真实界面、一张桌面、一张地图、一块白板、一条流水线、一页报纸……）。
  观众**从画面里的一个物体进入这个世界**（推进窗口、翻开那页、沿着那条线），不是凭空切进去。
- **手法**：怎么讲。前后对照、倒计时、一个数字贯穿全片、一张清单越贴越满、跟着一份文件走、同一画面开头空结尾满、问答、拆解再组装……
- **形式**：用什么做。真实录屏推近、重绘界面、纯字、图表、手绘、拼贴……

三条里至少一条是**大胆的那一条**（换一个世界或换一种形式，不是换配色）。写出三条各自的前两秒，
问用户选哪条（或推荐一条并说明理由）；没选上的两条在交付说明里提一句。

## 结构（两种片型通用的骨架）

1. **钩子（前 3–8 s）**：结果或痛点，用观众自己的话；不放 logo 开场、不放"大家好"。**第 0 帧就是封面**：
   开场第一句或主视觉 0 s 已经在画面上，不从黑场淡入（`check.mjs` 的 `first_frame_empty`）。
   例："对手刚把价格砍了一半。我们原来的报价，还守得住吗？"
2. **现状的代价**：2–3 个有出处的数字，或"现有手段各缺一块"（每项一句缺点）。
3. **一句话定位**：产品名 + 为谁、在什么时候、做成什么。这里第一次出 logo。
4. **三步 / 三章**：每步一个动作 + 一个看得见的结果。旁白片用真实界面；动效片用重绘 UI 的章节 01/02/03。
5. **证据**：结果画面停够读的时间、关键数字放大，但每 2–4 s 要有一样新东西（数字落定、第二个指标、一处标注）；
   再给"为什么可信"（可追溯、可复现、边界清楚）。
6. **广度（可选）**：同一框架还能做什么，3–6 个标签，一句短句收束（如"换场景，不换工具"）。
7. **一个行动号召**：只给一个入口；以产品名结尾；免责声明在这里完整出现。

发布片的节拍比例（按总时长折算）：钩子 8%、转折 12%、揭示 8%（落在 20–30% 处）、证据 40%（3–6 个动作）、
回报 20%（落在 60–80% 处）、口号 8%、片尾 8%。片尾 logo 占画面宽 15–30%，行动号召停 1.5–3 s。

上面是默认骨架，不是唯一答案；每个风格 `STYLE.md` 第 11 节列了它擅长的其他结构、开场和结尾。

## Treatment（选定故事线后写 `TREATMENT.md`）

1. **一句话梗概和弧线**：铺垫 → 转折 → 结尾；结尾最好呼应开场（同一个画面，这次是满的 / 做对了）。
2. **标杆**：选一两部为这个风格**和这个题目**定水准的作品（发布片、片头、广告），写下**学什么**（构图、节奏、镜头语法、色彩逻辑、配乐结构）
   和**不拿什么**（界面、logo、字体文件、旋律、具体镜头、角色）。标杆只写在 TREATMENT.md 里，不进成片。
3. **分镜表**：每个镜头的景别（全 / 中 / 近 / 特写 / 插入）、运动（推、拉、移、跟、甩）、时长和**为什么这样拍**。
4. **节拍表**：逐秒；**提示点表**：速度、小节网格、每段配器、每个切点 / 关键动作 / 字幕落在哪一拍（对应 `cues.json`）。
5. **声音表**：每段的环境底、主要拟音（各自的画面原因）、音乐状态（进 / 减 / 静）。
6. **字幕与标题**：字也是风格的一部分，按所选 `STYLE.md` 第 4 节。

一个**招牌动作**放在情绪最高点：只有这个风格能做的那一下（粒子爆出、光扫、刀切、圈重点、字形爆发……，见 `STYLE.md` 第 8 节），
挑一个或为这个故事发明一个。多余的梗砍掉：缩略图大小都能看懂的一个，胜过看不懂的三个。

## 文案

- 每屏一个意思；一行 ≤ 14 个汉字（竖屏约 8 个），最多一个强调词（`.g.warm` / `.g.cool`）。
- 动词开头、业务语言；内部代号、模型编号、技术缩写换成观众听得懂的词。
- 对仗短句最好记："不用安装。不用配置。一句话就够。" / "左边做决定，右边算结果。"
- **不用空话**：赋能、颠覆、革命性、一站式、无缝、极致、全新升级、轻松搞定、秒级（除非实测）、"只需几秒"（除非实测）；
  英文的 unlock / seamless / supercharge / game-changer / effortless 同理。第一句不用"隆重推出""为您介绍"。
- 旁白比屏幕字多一点信息，但不逐字重复屏幕；屏幕字是旁白的"标题"。
- 中文旁白语速 4–5 字/秒；一个场景的旁白 ≤ 2 句（约 9 s）。旁白说到哪样东西，那样东西就在那时出现。

## 节奏与画面

- 静音也能看懂：大字 + 烧录字幕。
- **按观众的速度，不按秒表**：字入场完成后要停够阅读时间，`check.mjs` 逐段查（[review.md](review.md)）。规则按词计：
  0.5 s + 每词 0.3 s；动效片 `--pace promo` 允许到它的 75%，讲解、故事、杂志类用 `--pace calm` 要停满。
  要快，就减少每屏的字，不要在人读完前切走。
- **快慢交替**：至少一次明显的加速或减速，至少一处让观众喘口气（长镜头或停住）；全片一个速度就是失败。
  招牌时刻前留 0.3–0.75 s 的静止，超过 0.75 s 的空屏就是断了。
- 一个动作、一个声音、一个切点，但不要每拍都切；留时间看。每 2–4 s 画面上要有一样新东西，完全不变超过 3 s 就死了。
- **到位就停**：每个场景只有一个焦点在动；其他元素落定后**完全静止**，不呼吸、不漂浮、不慢推（`idle_drift`）。
  要动镜头就带着目的动：从全景推到此刻该看的那一块。
- **动效的数**：
  - 缓动按角色分：入场减速落定（expo / quint out），镜头运动两头缓（inout），离场加速（in）。
  - 离场比入场短 40–50%；下一个入场在上一个离场进行到 30–50% 时开始，不排队。
  - 错峰：逐字约一帧、逐词 60–120 ms、列表项 40–80 ms。
  - 标题落定后纹丝不动；同一部片子里的标题入场换着用（遮罩上升、逐字、整块），不要每个都一样。
  - 快速运动给 6–12 px 的文字运动模糊，整屏甩镜头 15–20 px（风格钩子里的 `blur`）。
  - 入场方式由风格统一（`K.text` / `K.item`），同一片子里不混用风格之外的入场。
  - 转场时长跟能量走：平静 0.5–0.8 s，中等 0.3–0.5 s，高能 0.15–0.3 s；同一部片子里选一档为主。
- **数据动起来的规矩**：数字用等宽数字（`K.count` 已设 tabular-nums，不跳宽），数到终点不回弹、不过冲，最后一帧是精确原值；
  同一时刻只有一个数在跑；图表按"坐标轴 → 数据 → 标注 → 结论"的顺序搭；标题直接说结论（"成本降了一半"，不是"成本对比"）；
  最后的数字或图表落定后至少停 2 s 再走。
- **转场要有原因**：一部片子用 3–5 种转场，每一种都由画面里的动作引出（物体推出画面、遮罩扫过、镜头穿过窗口）；
  硬切不超过三分之一；两个不同的世界之间不用交叉淡化。运动方向跨切点保持一致：从右边出去的，下一场从左边进来；
  全片有一个主方向。
- **镜头要有理由**：至少用三四种不同的镜头运动和景别变化（推近、拉远、平移、插入、冻结……）；转场用风格自己的语法（`scene` 钩子），不要全片默认淡入淡出。
- 推近（punch-in）1.5–2×，缓入缓出（`K.inout`），推近目标是用户此刻该看的那一块；关键时刻主体至少占画面高度的三分之一。
- 章节标题卡 ≥ 2 s；关键时刻（logo、结论）的招牌动作与 `impacts` 同一时刻。
- **字号**以画面短边计：要读的字 ≥ 短边的 2.6%（1080 → 28 px），主标题 72–112 px，副标题 30–42 px。
  标题按字数分档：≤ 6 字 112 px，7–10 字 96 px，11–14 字 80 px；更长就拆成两屏，不要无限缩小。
  会在会议室投影或大屏播放的片子，要读的字下限提到 40 px（1080p）。
  比这小的只能是不需要读的装饰（窗口标题栏、行号、坐标刻度），标 `data-noread`。脚注和免责声明同样 ≥ 28 px、用 `--sub`。
- **安全区**：字在 90% 动作安全框内（1080p 左右 96 px、上下 54 px），关键字在 80% 标题安全框内（左右 192 px、上下 108 px），
  下方给字幕留 140 px；字幕不压主体。
- **压缩后的画面**：整屏的深色线性渐变在 H.264 里会出色带，用径向渐变或加一点颗粒；不透明度 5% 的氛围色压缩后就没了，要看得见用 15–25%。

## 发布片：用真实界面

- 产品界面用**真实录屏或真实截图**，不画假的仿制界面；没有素材时明说是重绘，并只画产品真有的能力。
- 每个功能三拍：**交代工作区**（全屏看清在哪）→ **隔离动作**（推近 1.6–2×，推近后界面字 ≥ 26–28 px）→ **回到结果**（拉回，结果落定）。
- 一个功能演示在画面上停 7–10 s（交代、动作、结果三拍走完），比这短观众看不清做了什么。
- **界面保真**：录屏和截图不调色、不加滤镜、不改混合模式，风格只管窗口外框（`check.mjs` 的 `shot_treated`）；
  推近不要超过截图的原始分辨率太多（`media_soft`），要推得更近就用 `deviceScaleFactor: 2` 重截。
- **脱敏在取素材时做**：抽帧、截图之前就遮掉或避开账号、token、客户名，不要指望渲染时盖住（盖错一帧就漏了）。
- **光标**：从画面外进来，不凭空出现；以箭头尖为支点（缩放、点击都围绕尖端）；点击是按下缩到 0.84、0.1 s，再 0.22 s 回弹；
  每一次点击都要引出下一拍（界面变化、推近、切镜），没有结果的点击删掉；做完从最近的画面边出去。
  光标占画面宽 4–7%，移动走弧线、先慢后快再慢，本身不抢戏。
- **讲版本更新时说准状态**：提议中、已合并、已发布是三回事，片子里写清是哪一种；展示代码只放 2–4 段小改动，每段几行，不放整屏 diff。

## 竖屏（1080×1920）

- 平台的按钮和文案会盖住上下两端：正文放在 168–1330 px 的高度带里，右侧操作栏（约 150 px 宽）下不放字。
- 标题约为横屏的 1.35 倍，字 ≥ 28 px，一行约 8 个汉字；镜头更短（1–2 s 一换）。
- 模板按横屏写，竖屏要重排版式（字号、栏位、上下堆叠），不是只改 `--size`。

## 一个母版，多个版本

- 要多个时长或画幅时，先定一个母版（通常是最长的横屏），其他版本从它**重新构图**，不是裁切：每个版本单独一份 timeline
  （`timeline-30s.json`、`timeline-9x16.json`），共用 film.html 和素材。
- 时长按 60 → 30 → 15 → 6 s 往下砍：30 s 留钩子、一步、证据、口号；15 s 留钩子、证据、口号；6 s 只剩一个画面加 logo。
  砍掉的是整段，不是把每段都压快。
- 每个版本各跑一遍 check 和 verify。

## 声音是半部片子

- **每个音效都有画面原因**：落位、切换、打字、点击。没有画面动作的音效删掉；声音的材质跟风格走（玻璃、纸、键盘、马克笔各不相同）。
  `music.mjs` 的 `ticks` / `whooshes` / `impacts` 按风格的调色板出不同的音色。
- **声音晚画面一帧**：音效的峰值落在画面动作之后一帧，听起来才是被画面"引起"的（`music.mjs` 默认 `lag` 一帧，`"lag": 0` 关掉）。
- 重复出现的音效轮换 2–3 个版本（`music.mjs` 自动轮换音高、音量和音色），同一个声音连响三次耳朵就听出是循环。
- **三层**：环境底、拟音（跟动作）、音乐；拟音比底高 3–6 dB；旁白时只有音乐闪避，人声比垫乐高约 15 dB，拟音不闪避
  （`music.mjs --sfx` 分轨，`mix.mjs --timeline` 按旁白时间提前压，见 narrated.md「音频」）。
- **用授权曲时**：选一个入点让第一个重拍落在第一个关键动作上；结尾落在乐句的终止处（一个落地的和弦或重拍），
  不要在乐句中间淡出；长度不够就在段落边界剪，不在小节中间剪。
- 手机和笔记本的喇叭听不到 150 Hz 以下：底乐的能量不能都在低频（`verify.mjs` 会报）。
- **至少两处真正的静默**（或接近静默），放在转折或高潮前；静默后的第一个声音应该是全片最重要的声音之一（`breath` 提示点）。
- **用声音转场至少两次**：下一场的声音提前进（J-cut），或上一场的声音拖过切点（L-cut）。
- 不用万能的"钢琴加弦乐"：用风格声音调色板里的乐器（`STYLE.md` 第 7 节，`cues.json` 的 `palette`）。
- 合成音乐是占位：告诉用户可以换成授权曲。响度：成片 −16 到 −14 LUFS，true peak ≤ −1 dBTP（`mix.mjs` 归一，`verify.mjs` 会报）。
  `verify` 只测量，不试听：交付说明里写"响度已测量，未经人耳试听"。

## 不是模板的翻版（写完 Treatment 后、交付前各查一次）

拿自己的片子和起步模板比这六项：**结构、开场、招牌镜头、镜头路径、配乐形状、结尾**。至少四项要不同；相同的那几项重新想。
交付前把 `review.mjs` 的 beats 图和模板的预览图放在一起再看一眼，并对照上面的黑名单。模板里的占位文案（"工具 A""一句话定位"）一个都不能留。

## 改片

- **一次改一个变量**：用户说"快一点"，先问或定下是哪一处、改成多少（"第 3 场从 9 s 到 7 s"），不要顺手把别处也改了。
- 要求写成绝对值，不写相对值："标题 96 px"，不是"大一点"；"停 2 s"，不是"久一点"。
- **冻结**：用户确认过的段落（文案、镜头、时长）标成冻结，后面的修改不碰它们；要动先说明。
- "提前一点""晚一点"有歧义（是整段平移，还是只动入场？），改之前说清楚按哪种理解。
- 每轮修改记在片子目录的 `REVISIONS.md`：日期、要求原话、改了什么、改了哪个文件。

## 地图

只要画面里有地图、地球或卫星图：

- **不画国界，除非片子就是讲国界的**。画海岸线、地形、街道即可；优先局部视图而不是世界地图，有争议的地区放在画面外。
- **画到中国就画完整**：台湾、海南、南海诸岛及断续线（在画面内或用插图）、钓鱼岛及赤尾屿都要有；台湾与大陆同色同处理；藏南、阿克赛钦按中国标准地图画。
