# 波普活力 Pop — 风格规格

> 明黄底、半调网点、粗黑描边和硬投影，字和卡片带着回弹跳出来，结尾一圈圈收拢再爆出描边彩纸。
> 借鉴（只学语法）：波普艺术和漫画印刷（半调网点、粗轮廓、平涂色块）；消费类 App 的活泼发布短片（弹跳、贴纸、彩纸）。不照搬任何漫画角色、艺术作品或品牌吉祥物。

## 1. 本质，以及它不是什么

- 一眼认出：**黄色半调底**、**粗黑描边 + 硬投影卡片**、**几个平涂色圆点散布背景**、**弹跳入场**、**彩纸爆发**。
- 气质是"好玩、马上能用"：适合面向大众、年轻用户、轻量工具、活动推广。
- 不是星云（没有暗色和发光）；不是白板（不是手写、线不抖）；不适合严肃的合规、医疗、金融类主题——除非刻意反差。

## 2. 材质与渲染

- 底：`--bg` 明黄，叠一层 radial-gradient 半调网点；两三个大色圆（粉、蓝，86 / 64 px）固定在角落。
- 卡片：白底、3 px 黑描边、8 px 硬投影（不模糊）、圆角 20 px。
- 按钮和胶囊（`.pill` `.btn` `.ghost`）同样黑描边 + 硬投影。
- 标记：粗黑描边、平涂色块。
- 不用渐变、不用模糊、不用发光。

## 3. 色彩逻辑

- 黄底 + 黑墨是基础；平涂类别色 `--c1..--c6`：蓝 `#2f7bff`、粉 `#ff4fa3`、绿 `#1fbf5a`、橙 `#ff7a00`、紫 `#8b5cf6`、白。
- 强调色 `--accent` 是粉；`.g.warm` / `.g.cool` 是平涂的粉 / 蓝，带黑描边，不是渐变。
- 一屏最多三种类别色，否则像彩虹糖。

## 4. 字体与字幕

- 标题：圆润粗体（Arial Rounded MT Bold / Segoe UI Black / 雅黑 Bold / 苹方 Semibold），800–900，字距 −1%。
- 字幕：白底黑描边胶囊、硬投影，像贴纸。
- 字号可以比别的风格更大一档；短词、感叹、数字都可以独占一屏。

## 5. 运动质感

- 回弹是本风格的签名：`K.text` 逐字从 0 放大并带 ±13° 随机倾角，`back(p, 2.2)` 过冲后落定；倾角由字符序号哈希决定，每帧一致。
- `K.item`：从 0.7 倍弹到 1 倍、从下方 30 px 跳上来、带 −4° 倾斜回正；离场向下掉 60 px 并转 6°。
- 场景：圆形光圈打开 / 关闭（`clip-path: circle()`）。
- 节奏快、动作短（0.35–0.55 s），但每个弹跳之后要停稳。

## 6. 镜头语法

| 动作 | 表达 | 适合 |
|---|---|---|
| 光圈开合 | 换场、聚焦 | 章节切换、揭示 |
| 贴纸一张张拍上 | 叠加好处 | 功能列表、亮点 |
| 大字独占一屏弹出 | 喊出来 | 口号、数字、"免费" |
| 快速三连切 | 热闹、多样 | 多个场景、多种用户 |
| 镜头抖一下（2–3 帧） | 冲击 | 落定、点击 |

## 7. 声音调色板

- `music.mjs` palette **pop**：明亮 pad、拨弦琶音、拍手军鼓、tick = "啵"一声，whoosh = 快速 zip，impact = boom + 和弦。
- 拟音：贴纸拍下、按钮点击、弹簧"嘣"、气球。
- 鼓点密但留两处急停：彩纸爆发前一拍全静。

## 8. 招牌动作

- **收圈 + 彩纸**（`hit` 已实现）：三圈粗黑环向中心收拢，落点爆出 70 片描边彩纸（圆、方、三角、波浪线），带重力下落并渐隐。*适合*：logo 揭幕；活动开始；"完成！"。
- **贴纸墙**：好处一张张拍到画面上，略有倾斜和重叠。*适合*：功能亮点；用户评价（只用真实授权的）；集成列表。
- **大字弹出**：一个词或数字放满屏、过冲落定、镜头轻抖。*适合*：口号；价格；上线日期。
- **光圈转场**：从一个按钮或圆点打开下一个场景。*适合*：点击后的结果；进入下一章。

## 9. 常见坑

- 回弹太大、太多 → 一屏只有一个主角在弹，其他直接出现或小幅弹。
- 半调网点在压缩后出现摩尔纹 → 网点间距 ≥ 18 px（默认 26 px）、对比要低。
- 彩纸挡住 logo 太久 → 1.4 s 后开始渐隐，2.2 s 全部消失（默认如此）。
- 黑描边在小字上糊 → 描边只给卡片和大字，正文不描边。
- 严肃主题用波普显得轻浮 → 先问清受众；必要时换 keynote 或 editorial。

## 10. 引擎

- `style.js`：`text`（逐字过冲弹出 + 固定倾角）、`item`（弹入 / 掉落离场）、`mask`（过冲遮罩）、`lockup`（整体从 0.6 弹到 1，标记转 −30° 回正）、`scene`（圆形光圈）、`hit`（三圈收拢 → 描边彩纸 + 重力）。`draw` 为 `out3`。
- 可调：`back()` 的过冲强度（2.2 / 1.9 / 2.4）、`COLS` 彩纸色（与 `--c1..--c6` 一致）、彩纸数量 70、重力 900。

## 11. 变化空间

- 结构：**一张清单贴满**（每个好处是一张贴纸，最后满墙）；**之前 / 之后**（灰色的旧日常 → 光圈打开变成黄色新日常）；**挑战**（三个小任务，每个一秒钟完成）。
- 开场：**一个按钮在中间等着被点**；**一个大大的问号弹出来**；**三个色圆跳进画面排成一行**。
- 结尾：**彩纸落完，只剩 logo 和一个按钮**；**所有贴纸一起掉下去，露出 logo**；**光圈收成一个圆点，圆点就是 logo 的一部分**。
