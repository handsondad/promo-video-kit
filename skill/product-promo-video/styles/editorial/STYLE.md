# 杂志纸本 Editorial — 风格规格

> 一本好杂志翻开来：奶油色纸、衬线大标题、宽留白、一个陶土色强调，节奏从容，像在读而不是在看广告。
> 借鉴（只学语法）：长篇特稿和年度报告的排版（衬线标题、首字、细线、引语）；纪录片字幕的克制。不照搬任何刊物的版式、刊头字体或插图。

## 1. 本质，以及它不是什么

- 一眼认出：**奶油纸面 + 轻微纸纹**、**衬线标题**、**大留白**、**细线和小菱形装饰**、**陶土色强调**。
- 气质是"值得认真读"：可信、成熟、慢。适合讲理念、讲案例、讲为什么。
- 不是瑞士网格（不是无衬线、不卡拍、信号色不刺眼）；不是白板（不是手写）；不是发布会（没有暗场和发光）。

## 2. 材质与渲染

- 纸：`--bg` 奶油色，叠一层内联 SVG 噪声（data URI，极淡），四周略暗。
- 卡片：白一点的纸色、1 px 暖灰细边、几乎没有阴影，圆角 3 px。
- 装饰只用细线（1–1.2 px）、小菱形、引号；不用图标堆。
- 照片或截图放进来时加 1 px 细边和下方一行图注。

## 3. 色彩逻辑

- 墨色是暖黑（`--ink` `#1f1a16`），次级是暖灰。
- 一个强调色陶土（`--accent` `#c2502e`）用于关键词、引语符号、行动号召；`.g.cool` 用深海军蓝，作为第二种强调（只给产品名）。
- 类别色 `--c1..--c6` 是低饱和的大地色系（陶土、海军蓝、橄榄、赭石、灰紫、石板）。
- 不用纯黑、不用荧光色。

## 4. 字体与字幕

- 标题：衬线（Noto Serif SC / 思源宋体 / 宋体 / Georgia），500–600，字距 0。
- 正文：无衬线（雅黑 / 苹方），保证小字可读；也可以全用衬线做更强的书卷感。
- 字幕：纸色底、上方一条 1 px 墨线、零圆角、衬线字，不加粗。
- 引语用大号陶土色引号起头；数字用旧式数字风格的衬线更像杂志。

## 5. 运动质感

- 慢：`inout` 缓动，单个动作 0.8–1.1 s；字间隔 24 ms；节奏比默认慢 30%。
- `K.text`：逐字淡入 + 上浮 16 px，**不模糊**。
- `K.item`：淡入 + 上浮 ≤ 22 px，0.8 s 以上；离场淡出 0.5 s。
- 场景：慢交叉淡化。
- 没有回弹、没有闪烁、没有步进。动起来的东西越少越好。

## 6. 镜头语法

| 动作 | 表达 | 适合 |
|---|---|---|
| 极慢推近（整屏 1 → 1.02） | 沉思、专注 | 引语、核心观点 |
| 翻页（左右交叉淡化） | 下一章 | 案例分段 |
| 局部放大配图注 | 证据 | 截图、数据来源 |
| 对开页（左文右图） | 叙述 + 证据 | 方法说明、客户故事 |
| 留白停顿 | 让一句话落地 | 结论前 |

## 7. 声音调色板

- `music.mjs` palette **felt**：温暖 pad、毛毡钢琴、刷子鼓或无鼓；tick = 钢琴单音，whoosh = 翻纸声，impact = 钢琴和弦。
- 留白比声音更重要：至少两段 1 s 以上只有房间底噪或 pad。
- 拟音：翻页、钢笔、纸张轻放。

## 8. 招牌动作

- **细线与菱形**（`hit` 已实现）：lockup 下方一条细线从中间向两边画开，两端各出一个陶土色小菱形。*适合*：logo 落定；章节结论；签名。
- **首字下沉**：段落第一个字放大、陶土色，其余正文慢慢出现。*适合*：故事开篇；案例引子。
- **大引语**：整屏只有一句话和一个大引号。*适合*：用户原话（只用真实、授权的话）；产品理念。
- **图注揭示**：截图先出，图注慢一拍出现，解释它为什么重要。*适合*：功能截图；前后对比。

## 9. 常见坑

- 纸纹太重像脏 → 噪声要淡，大屏上看不到颗粒才对。
- 衬线中文太细在压缩后发虚 → 标题 ≥ 600 字重、≥ 56 px。
- 太慢变拖沓 → 慢的是单个动作，不是信息密度；每屏仍然要有一个清楚的新信息。
- 引语用编造的"用户说" → 只用真实、授权的话；没有就用产品自己的一句理念。

## 10. 引擎

- `style.js`：`text`（逐字淡入上浮，无模糊）、`item`（慢淡入上浮）、`mask`（慢遮罩上升）、`lockup`（整体上浮淡入，名字逐字）、`scene`（交叉淡化）、`hit`（中心向两边画开的细线 + 两端菱形，2.9 s 后淡出）。`draw` 为 `inout`，连线不带火花。
- 可调：`hit` 里细线半宽 520 px、菱形大小、`INK` / `ACC`（与 `--ink` / `--accent` 一致）。

## 11. 变化空间

- 结构：**一篇特稿**（标题 → 引子 → 三节 → 结语，像翻一本杂志）；**一个人的一天**（时间线 + 引语）；**问答**（每屏一个问题、一个回答）。
- 开场：**一句引语**独占一屏；**刊头式的大标题**慢慢出现；**一张截图配图注**，标题后出。
- 结尾：**合上杂志**，封底只有 logo；**最后一句引语之后的长留白**；**签名式的细线和日期**。
