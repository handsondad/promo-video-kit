# 终端荧光 Terminal Phosphor — 风格规格

> 老式荧光屏终端：黑底绿字、扫描线、块状光标逐字打出，面板闪烁着亮起、像 CRT 一样关机。
> 借鉴（只学语法）：命令行界面和早期荧光显示器（等宽字、光标、扫描线、余辉）；开发者工具发布片里的"打一行命令就搞定"。不照搬任何真实终端程序的界面、主题文件或 ASCII 艺术。

## 1. 本质，以及它不是什么

- 一眼认出：**黑底荧光绿**、**全等宽字**、**块状光标**、**整屏扫描线**、**一条缓慢滚动的亮带**。
- 讲的是"一个命令完成一件事"：精确、即时、可复现。
- 不是暗场发布会（没有柔和面板和单一强调色的克制）；不是蓝图（不是线稿）；不是黑客电影（不要满屏乱码雨、不要骷髅）。

## 2. 材质与渲染

- 屏幕：`--bg` 近黑带绿；`body::after` 画 3 px 周期的扫描线（每周期 1 px 暗线，透明度 28%）；四周暗角。
- `canvas#bg`：一条 300 px 高的淡绿亮带从上往下慢慢滚过（`bg` 钩子），模拟刷新。
- 面板：1 px 绿色细边、4 px 小圆角、几乎透明的绿色填充；没有阴影。
- 文字带轻微余辉：`text-shadow` 一层同色 0.35 透明度的光。
- 标记：logo 只描边，用荧光绿。

## 3. 色彩逻辑

- 主色荧光绿（`--ink` / `--accent`，`#39ff88` 一族）；次级是暗绿（`--sub` / `--dim`）。
- 只有两个例外色：琥珀（`--warn`，警告）、红（`--bad`，错误）。其他类别色 `--c1..--c6` 都是绿的不同亮度和青绿。
- 不出现白色大面积；最亮的就是绿。

## 4. 字体与字幕

- 全部等宽：Cascadia Mono / Consolas / SF Mono / JetBrains Mono + 等宽中文回落（雅黑）。
- 标题不比正文粗多少（600），靠尺寸区分。
- 字幕：深色底、1 px 绿边、零圆角、等宽字，前面一个暗绿 `> ` 提示符，像终端输出。
- 行动号召（`.ghost` / `.btn`）前自动加 `$ ` 提示符，警示胶囊（`.pill`）前加方括号里的感叹号（终端的警告标记）。
- 中文在等宽字里会变宽：一行不超过 24 个汉字。

## 5. 运动质感

- 打字：`K.text` 固定速率（每字 ≥ 30 ms），正在打的那个字是反色块（光标）；离场是快速退格（每字 14 ms）。
- 面板：`K.item` 0.3 s 内按 `[0, .7, .15, .9, .4, 1]` 闪烁亮起；离场像 CRT 关机——纵向压成一条亮线再消失。
- 场景：入场同样闪烁，离场从中线收拢。
- 连线（`draw`）按 12 级步进画出，不平滑。
- 节奏快：动作短、停顿明确，没有缓动漂移。

## 6. 镜头语法

| 动作 | 表达 | 适合 |
|---|---|---|
| 锁定一个提示符 | 等待输入 | 钩子、"只需要一行" |
| 输出滚屏 | 大量工作被自动完成 | 批处理、部署、测试通过 |
| 分屏（左命令右结果） | 因果 | 命令 → 产出 |
| 推近一行输出 | 关键结果 | 一个数字、一个"PASS" |
| 闪烁切换 | 换一个会话 | 换场景、换角色 |

## 7. 声音调色板

- `music.mjs` palette **chip**：方波琶音（16 分）、方波式 pad、芯片底鼓和噪声军鼓、tick = 短 blip，whoosh = 快速扫频，impact = 芯片和弦 + 下行扫频。
- 拟音：键盘敲击（每个可见的字一声太密，每 3–4 字一声即可）、回车、显示器开机的高频啸叫（很轻）。
- 静音很有力：命令执行前一拍全静，回车后结果出来再进鼓。

## 8. 招牌动作

- **扫描 + 字形爆发**（`hit` 已实现）：一条亮线从上往下扫过，到中心时 280 个字形向外迸散、渐隐。*适合*：logo 揭幕；"构建成功"；最终结论。
- **一行命令**：提示符后打出一条短命令，回车，下面滚出结果。*适合*：一键安装；一句话生成报告；自动化流程。
- **退格改写**：打错的词被退格删掉，换成正确的。*适合*：旧说法 → 新说法；"不是 X，是 Y"。
- **进度条**：等宽字符组成的进度条按步进填满。*适合*：处理过程；迁移；训练。

## 9. 常见坑

- 扫描线在 1080p 压缩后出现摩尔纹 → 周期不小于 3 px；竖版或缩小输出时检查一帧。
- 绿色太亮刺眼 → 正文用 `--sub`，只有标题和关键结果用最亮的绿。
- 打字太快读不完 → 每字 ≥ 30 ms，并按阅读时间留够停留（`check.mjs` 会查）。
- 光标反色块在渐变词上失效 → 已处理 `-webkit-text-fill-color`；自定义渐变时同样设置。
- 满屏乱码雨看起来像病毒，而不是产品 → 字形只在招牌动作里出现一次。

## 10. 引擎

- `style.js`：`text`（块光标打字 / 退格）、`item`（闪烁亮起 / CRT 关机）、`mask`（4 级步进）、`lockup`（标记闪烁，名字慢打）、`scene`（闪烁入场、中线收拢离场）、`bg`（滚动亮带）、`hit`（扫描线 → 字形爆发）。`draw` 为 `steps(x, 12)`。
- 可调：`FLICK` 闪烁序列、`GREEN`（和 `--accent` 一致）、打字速率 `st`、爆发字形集合。

## 11. 变化空间

- 结构：**一次会话**（全片是一次终端会话，每章一条命令）；**日志回放**（时间戳一行行出现，讲一天里发生了什么）；**对照**（左边手工十步，右边一条命令）。
- 开场：**黑屏只有闪烁的光标**；**一条报错**红色出现，接着被解决；**开机自检**，一行行 OK。
- 结尾：**`exit` 后屏幕关机收成一个亮点，亮点变成 logo**；**最后一行是安装命令，光标闪烁**；**滚屏停住，只剩一行 "done"**。
