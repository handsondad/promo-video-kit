# 星云玻璃 Nebula Glass — 风格规格

> 深蓝紫星空上的半透明玻璃卡片：逐字从模糊中浮现，关键词带一段连续渐变，粒子旋涡收拢、爆发、logo 落定。
> 借鉴（只学语法）：AI 与开发者工具的发布短片（暗色宇宙背景、玻璃 UI、节点连线、粒子揭幕）。不照搬任何一家的界面、logo、配色专有元素和文案。

## 1. 本质，以及它不是什么

- 一眼认出：**暗色星空 + 柔光晕**、**玻璃卡片**（深色半透明、1 px 细边、大圆角）、**一句一个渐变词**、**粒子爆出 logo**。
- 情绪是"宏大而柔和"：东西从虚到实，而不是卡拍落位。
- 不是暗场发布会（keynote 只有一个强调色、网格卡拍、没有渐变和粒子）；不是终端（不是等宽字和扫描线）；不是数据图表片。
- 它也是最接近"生成默认"的外观（深色虚空、辉光、粒子、玻璃卡片，见 craft.md「默认值黑名单」）：选它要有内容上的理由，
  并且用真实素材和一个只属于这部片子的招牌动作把它从默认值里拉出来。

## 2. 材质与渲染

- 舞台：`.stage` 三团径向光晕（中心蓝紫、右下暖橙、左上紫）叠在 `--bg` 上；56 px 极淡网格；`canvas#bg` 每帧画星空（`K.starfield`，种子固定，缓慢视差漂移和闪烁）。
- 卡片：`--card` 深色 72% 不透明，`--card-line` 细边，`--card-shadow` 大而软的投影 + 顶部 1 px 内高光。
- 光：只在中心球（`.hub .orb`）和 logo 上发光；其他元素不发光。
- 粒子：`K.swarm` 在 `canvas#fx` 上画，叠在场景之上；颜色取 `--c1..--c6`。

## 3. 色彩逻辑

- 中性色是冷蓝灰阶（`--ink` / `--sub` / `--dim`），从不偏暖。
- **渐变只给一个词**：`.g.warm`（橙→粉→紫）用于"结果、卖点"，`.g.cool`（蓝→青→紫）用于产品名。同一屏最多一个渐变词。
- `--c1..--c6` 是类别色（连线、进度条、色点），饱和但只出现在小面积上。
- 状态色：`--good` 绿、`--warn` 琥珀、`--bad` 玫红，只表示状态。

## 4. 字体与字幕

- 系统无衬线（Segoe UI Variable / SF Pro / Inter + 微软雅黑 / 苹方），标题 700，字距 −1%。
- 字号：主标题 72–112 px，章节标题 92 px，要读的卡片正文和脚注 ≥ 28 px（1080p）；窗口标题栏等装饰可以更小，标 `data-noread`。
- 字幕 `.sub`：底部居中深色半透明圆角条，31 px。停留 ≥ max(1.8 s, 语音 + 0.6 s)。

## 5. 运动质感

- 30 fps 逐帧，无步进。缓动以 `out3` / `out5` 为主，场景内推近用 `inout`。
- 文字：`K.text` = 逐字从 14 px 模糊中上浮 22 px（间隔 35 ms），离场反向。
- 元素：`K.item` = 淡入 + 上移 30 px（可加 6–10 px 模糊、可从 0.7 倍放大）。
- 卡片到位后保持静止，不漂浮、不呼吸（"柔和"来自入场，不来自落定后的晃动）；只有星空和粒子一直在动；同一屏只有一个焦点在动。

## 6. 镜头语法

| 动作 | 表达 | 适合 |
|---|---|---|
| 慢推（整屏 scale 1 → 1.03） | 专注、沉浸 | 钩子问题、定位句 |
| 换词叠印（多个词同位置依次浮现/消散） | 列举、对比 | "你已经有了 X / Y / Z" |
| 中心球 + 连线放射 | 一个核心连接多个能力 | 平台能力、集成、编排 |
| 标题卡 → 内容（1.4 s 后切） | 章节感、节奏 | 三个卖点依次展开 |
| 粒子收拢 → 爆发 | 汇聚成一个答案 | logo 揭幕、结论 |

转场：场景内元素自己淡出/模糊消散；不用硬切和推拉门。

## 7. 声音调色板

- `music.mjs` palette **synth**：锯齿 pad、正弦 sub bass + 侧链、电子底鼓、8 分 hats、正弦琶音（延迟回声），bell 轻铃，空气 whoosh，impact = 上扬噪声 + 低频冲击 + 和弦闪光。
- 粒子爆发和 logo 落定同一帧，对应 `impacts`。开场换词每拍一个 `ticks`。
- 收尾 `breath` 留白 0.6–1 s，最后一个重音之后只留 pad 尾巴。

## 8. 招牌动作

- **粒子揭幕**：1.5 s 收拢成点，爆发出冲击环和闪光，logo 同时从 1.12 倍、8 px 模糊落定。*适合*：产品名首次出现；最终结论；"所有能力汇成一个入口"。
- **换词叠印**：同一位置三个词依次从模糊浮现再消散，最后落到一句"缺什么"。*适合*：现有工具各缺一块；三个用户群；三种场景。
- **连线火花**：曲线描出后两颗光点沿线流动。*适合*：数据流向；任务分发；系统集成。
- **渐变词**：整句白字只有一个词带连续渐变。*适合*：结果、收益、产品名。

## 9. 常见坑

- 渐变词断色 → 逐字拆分后必须 `K.measure()`（`K.film` 首帧已做），字体加载后再量。
- 粒子盖住 logo 太久 → 爆发后 0.6 s 内透明度要降到 30% 以下（默认已是指数衰减）。
- 卡片太多太亮 → 背景卡片降到 45% 亮度并加 2–3 px 模糊，让焦点留在大字上。
- 星空太密抢戏 → `starfield({ count })` 降到 300–400。

## 10. 引擎

- `style.js` 只定义 `bg`（星空）；`text` / `item` / `mask` / `lockup` / `hit` 用 kit 默认（`K.reveal` / `K.show` / `K.maskIn` / 模糊落定 / `K.swarm`）。
- 可调：`K.reveal` 的 `st`（字间隔）、`blur`、`dy`；`K.swarm(canvas, { count, palette })`；`K.starfield(canvas, { count, drift })`。

## 11. 变化空间

- 结构：**一条数据流**（从输入一路流到结果，每章是流经的一站）；**三个人**（三个角色各用一次产品，最后汇合）；**倒计时**（发布前 3 / 2 / 1，每一拍一个能力）。
- 开场：**一个旋转的空中心球**，逐渐有节点连上；**一句痛点大字第 0 帧就在画面上**，随后关键词变成渐变；**三张卡片同时报错**。
- 结尾：**所有连线一起亮起再熄灭，只剩 logo**；**粒子散成星空的一部分**；**回到开场的空中心球，这次它是满的**。
