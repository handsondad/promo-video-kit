# 蓝图工程 Blueprint — 风格规格

> 蓝图纸上的工程制图：白色线稿、构造线、尺寸标注，字像绘图仪一样逐笔画出；黄色铅笔只用来标注。
> 借鉴（只学语法）：机械与建筑蓝图（网格纸、构造线、剖面、尺寸链）；技术专利图的标注方式。不照搬任何真实图纸、厂商标识或专利内容。

## 1. 本质，以及它不是什么

- 一眼认出：**蓝底 + 两级网格**、**白色细线框**（无填充、直角）、**虚线构造线和外框**、**黄色尺寸标注**。
- 讲的是"它是怎么构成的"：结构、连接、比例，而不是情绪。
- 不是暗场发布会（没有发光、没有面板阴影）；不是白板（线是直的、精确的，不是手写）；不是终端（不是等宽满屏、没有扫描线）。

## 2. 材质与渲染

- 纸：`--bg` 蓝图蓝，24 px 细网格（白 5.5%）+ 120 px 主网格（白 13%），四周轻微暗角。
- 线：卡片 1.5 px 白线框 + 9 px 外的 1 px 虚线构造框（`outline`）；圆角为 0。
- 填充几乎透明（白 3.5%），像描图纸叠在蓝图上。
- 标记：logo 只描边不填充，折线和点用黄色铅笔色。
- 一切线条都是"画出来"的：`K.stroke` / `draw` 线性，无火花。

## 3. 色彩逻辑

- 两种"墨"：白（`--ink`，线稿和正文）和黄铅笔（`--accent`，只用于标注、尺寸、强调词、行动号召）。
- 次级蓝灰（`--sub` / `--dim`）用于注释和网格。
- 类别色 `--c1..--c6` 是低饱和的浅蓝、浅绿、浅红、浅紫，只在线条上出现，不大面积填充。
- 不出现纯黑；暗处是更深的蓝。

## 4. 字体与字幕

- 工程感窄体：Bahnschrift（Windows）/ DIN Alternate（macOS）/ Roboto Condensed + 微软雅黑；标题 600，字距 +1%。
- 标签、编号、尺寸用等宽字（`--mono`），可加宽字距、可全大写。
- 字幕：深蓝底、1.5 px 白线框、直角，像图纸上的标题栏。
- 数字带单位和公差的写法更像图纸（"R 300"、"±0.5"），但只写真实的值。

## 5. 运动质感

- 线性为主（绘图仪匀速），关键停顿用 `inout`。
- `K.text`：每个字从左到右被"画"出（clip 线性 0.12 s，字间隔 30 ms），离场整体淡出。
- `K.item`：框先画出上边再向下展开（clip 同时从右和下收缩），像先画轮廓再画内容。
- 场景转场是叠图纸：慢交叉淡化（`inout`）。
- 不回弹、不缩放、不模糊。

## 6. 镜头语法

| 动作 | 表达 | 适合 |
|---|---|---|
| 平移沿一条尺寸链 | 测量、比较 | 规格对比、性能差距 |
| 推进到一个局部详图 | 关键部件 | 核心模块、接口、算法一步 |
| 剖面（一半擦去显出内部） | 内部结构 | 架构分层、数据流 |
| 爆炸图（部件沿轴分开） | 由什么组成 | 组件清单、技术栈 |
| 锁定 + 构造线逐条画出 | 推理过程 | 原理讲解、为什么可信 |

## 7. 声音调色板

- `music.mjs` palette **ambient**：低沉 drone pad（根音、五度、八度）、玻璃质感琶音（八分音符、长衰减）、机械 tick（双击）、swell 式 impact（和弦渐强后落一个玻璃和弦 + 低频）；没有鼓。
- 拟音：绘图笔"嘶"声、尺子落桌、圆规转动、纸张翻动。
- 节奏慢（76 bpm），给观众时间读图。

## 8. 招牌动作

- **构造线揭幕**（`hit` 已实现）：先画一个构造圆和十字线，再在下方画一条带箭头的尺寸线（标注可选）。*适合*：logo 落定；关键参数揭晓；"核心就在这里"。
- **逐笔绘制**：线框按真实的绘制顺序出现（外轮廓 → 主结构 → 细节 → 标注）。*适合*：架构图；工作流；一页方案。
- **尺寸对比**：两条尺寸链上下对齐，差值用黄色标出。*适合*：前后性能；成本对比；规格升级。
- **剖面**：擦去一半外壳露出内部层级。*适合*：系统分层；数据从哪来；安全边界。

## 9. 常见坑

- 线太细在 1080p 压缩后发虚 → 主线 ≥ 1.5 px，构造线 ≥ 1 px。
- 网格和内容抢 → 网格透明度不超过 13%，内容线条 ≥ 70%。
- 黄色用太多就不再是"标注" → 每屏最多两处。
- 窄体字没有中文字形 → 中文回落到雅黑/苹方，标题可改用 `--mono` 保持一致。

## 10. 引擎

- `style.js`：`text`（逐字左到右裁切画出）、`item`（先上边再向下展开）、`mask`（左到右画出）、`lockup`（标记自上而下画出）、`scene`（慢交叉淡化）、`hit`（构造圆 + 十字虚线 → 尺寸线、端部箭头、标注文字；1.2 s 后淡到 35%，3.4 s 后收掉）。`draw` 为线性、`sparks` 关闭由 `draw` 决定。
- 可调：`hit` 里的半径 `R`；标注文字默认不画，在片子的 CSS 里写 `:root { --hit-label: "v2.0"; }` 才出现——只写真实的值（版本号、发布日期），不要编数字。

## 11. 变化空间

- 结构：**从零画出一张图**（整片是一张图纸逐步完成）；**爆炸图**（合体 → 分解讲每个部件 → 合体）；**两张图对照**（旧架构 / 新架构叠在一起，差异用黄色描出）。
- 开场：**一张空白蓝图纸，标题栏先被填好**；**一条尺寸线先出现**，两端的东西还没画；**一个局部详图**，镜头拉远才知道它属于哪里。
- 结尾：**完整图纸缩小到标题栏里签上名字**；**所有构造线淡去，只留成品线稿**；**图纸翻面，背面只有 logo**。
