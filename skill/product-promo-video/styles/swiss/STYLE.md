# 瑞士网格 Swiss Grid — 风格规格

> 国际主义平面设计动起来：模块网格、一个字族、一个信号色，运动像印刷机一样准确。
> 借鉴（只学语法）：20 世纪中叶苏黎世学派海报的网格、左对齐、强烈尺度对比和"设计程序"；当代品牌识别系统在拍子上卡位的动态版本。不照搬任何一张历史海报的构图，不用受版权保护的字体文件，海报上不出现真实机构名。

## 1. 本质，以及它不是什么

- 纯 2D 平面设计在网格上运动：浅灰纸面、黑色字和色块、**一个**饱和信号色。
- **每个元素落在网格上、每个动作落在拍子上、什么都不弹跳**。
- 严谨中留一个例外：整个画面服从系统，唯一不服从的那个元素就成了主角。
- 极端尺度对比：巨大数字旁边是很小的技术注释。
- 不是发布会（没有渐变、发光、设备）；不是歌词动态字（字不飞、不转、不弹）；不是数据图（色块是图形质量，除非网格赋予它数量意义）。

## 2. 材质与渲染

- 画面网格：1920 × 1080，12 栏，左右边距 96 px，栏间距 24 px；`.stage` 上淡淡画出栏线（墨色 5.5%），让版式能对着网格读。
- 表面：纸面 `--bg`、白纸 `--card`、墨色、灰阶线、一个信号色。**没有渐变、没有阴影、没有颗粒、没有圆角**。
- 卡片顶边一条 6 px 墨色粗线，代替边框和阴影。
- 色块拼接处多画 1 px，避免旋转或缩放后出现发丝缝。

## 3. 色彩逻辑

- 纸、墨、灰，加**一个**信号色（默认 `#e30613` 红）。只有一样东西用信号色，那它就是主角；也只有它可以不精确。
- 叠印可以：黑字压在信号色上。
- 信号色可以是红、橙、群青或绿，按主题选，然后永远不加第二个。示例：`#eae9e5` / `#111` / `#e30613`；`#f2f0ea` / `#141414` / `#ff5a00`；`#e9ecef` / `#0b0b0b` / `#1f3fff`。
- 类别色 `--c1..--c6` 全是墨色和灰；状态"好"也用墨色，"坏"用信号色。

## 4. 字体与字幕

- 全片一个字族：新怪诞无衬线（Inter / Helvetica Neue 系统字 / Segoe UI + 微软雅黑 / 苹方），多个字重；≥ 90 px 时字距 −2%。
- **左对齐、右边参差**；一切落在网格线上；大块留白是版式的一部分（theme 把 `.center-x`、`.lock`、`.ctitle`、`.center` 都改成左对齐 120 px）。
- 字幕是版式的一部分，不是底部黑条：左对齐在栏线起点，上方一条 2 px 墨线，粗体。
- 注释行：19 px 中等字重，上方 1 px 细线；角落里放技术注释（模块尺寸、计数、小节号）。这些是版式装饰，标 `data-noread`，
  不承载观众要读的信息；要读的字 ≥ 28 px。

## 5. 运动质感

- 两种曲线：精确缓动 `K.snap`（近似 cubic-bezier(.7,0,.2,1)）用于卡位；线性用于画线、播放头和"例外"。**无回弹、无弹簧**。
- 时长是音符时值：卡位提前一个时值开始、在拍点落位。
- 入场是擦入或槽口上升，**从不淡入**：字从基线下的槽口里升起（`K.text`），元素从左往右擦入（`K.item`），离场是刀切——收成中线消失。
- 涟漪按与起因的距离排序。
- 30 fps 平滑，无步进：数字化的精确，不是手作。

## 6. 镜头语法

| 动作 | 表达 | 适合 |
|---|---|---|
| 锁定对开页 | 左因右果 | 规则被应用、前后对比 |
| 硬平移一页或一栏 | 系统的下一步 | 序列、目录、时间线 |
| 旋转 90° 停住 | 同一个东西换个读法 | 海报变乐谱、图表变地图 |
| 拉远成一墙作品 | 一个程序，很多产出 | 品牌系统、产品线 |
| 推进一个模块 | 系统的最小单位 | 一个像素、一个字母、一个数据点 |
| 画面分成等格 | 平行案例 | 选项、版本、团队成员 |

转场是擦除、刀切、镜头移动和重排（`scene` 钩子：从左擦入、向右擦出），绝不叠化。

## 7. 声音调色板

- `music.mjs` palette **motorik**：120 bpm 稳定脉冲，紧底鼓 + 2/4 拍军鼓、8 分 hats、8 分音符 bass（八度跳）、拨弦琶音、管风琴式 pad；tick = 干脆的咔嗒，whoosh = 纸张滑动，impact = 盖章一样的闷响 + 短和弦。
- 每加一条规则加一件乐器，是清楚的递进；"例外"出现的那一刻抽掉鼓。
- 拟音跟着印刷材料走，干、近、不加混响：活字咔嗒、直线笔"嘶"、裁纸刀、纸拍、盖章。
- 在强拍上让所有声音硬停，下一个卡位就成了事件。

## 8. 招牌动作

- **网格有意义**：栏和行变成数量（小时、楼层、年份）。*适合*：一周排期；楼宇楼层；城市分区。
- **卡位即拍子**：每一次落位都是一下打击乐。*适合*：功能清单；步骤；倒计时。
- **程序**：规则一条条作用到一件作品上，再用同一程序生成很多件。*适合*：品牌系统；模板库；一套报告。
- **刀切**：一条线穿过元素，元素收成中线消失。*适合*：砍预算；删掉一步；去掉一个功能。
- **规则线变信号色**（`hit` 已实现）：一条墨线横穿版面，在拍点变粗、变成信号色，最后被刀切掉。*适合*：logo 落定；结论；"就是这一条"。

## 9. 常见坑

- 栏太多太细像图表 → 更少、更宽的模块。
- "更好的版式"并不明显更好 → 一条强对角线、长短节奏、放大信号元素、出血、字压色块；只是倾斜不够。
- 旋转和加标签同时发生 → 先转、停住、再加标签。
- 视觉起点落在两帧之间会闪 → 起点放在整帧上。
- 模板里如有居中写死的布局（`justify-content:center`），在本风格要改成左对齐。

## 10. 引擎

- `style.js`：`text`（槽口上升，`slot()` 同时设 transform 和 clip-path，落定后清空）、`item`（左擦入 / 刀切离场）、`mask`、`lockup`（标记自下而上擦出，名字槽口上升）、`scene`（擦入擦出）、`hit`（墨线画过 → 变红加粗 → 2.6 s 后刀切）。`draw` 为线性，连线不带火花。
- 可调：信号色同时改 theme.css 的 `--accent` / `--bad` / `--c4` 和 `hit` 里的颜色。

## 11. 变化空间

- 结构：**时刻表**（24 行小时网格被这一天填满，一拍一行）；**字母表**（A 到 Z，每个字母是主题的一个模块）；**对照**（两个系统并排，直到一个元素越过中缝）。
- 开场：**一个点**放到页面上，网格从它长出来；**成品先出现**，再被拆回规则；**一个巨大数字**占满画面，原来是小版式里的一个细节。
- 结尾：**每个元素都被切掉后的空网格**；**角落里左对齐的一个词**；**例外离开画面**，系统合上它留下的空位。
